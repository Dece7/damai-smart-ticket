# 利用现有网关实现AI项目与全栈项目整合

## 架构图

```
┌─────────────────────────────────────────────────────────────┐
│                    完整整合架构                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  用户 → 全栈项目前端 (localhost:5173)                       │
│         └→ 登录 → 获取Token                                │
│                                                             │
│  用户 → AI项目前端 (localhost:8000)                         │
│         └→ 携带Token                                       │
│                                                             │
│  AI项目后端 → 网关 (localhost:6085)                         │
│               ├→ 验证Token                                 │
│               ├→ 获取userId                                │
│               └→ 转发到后端微服务                          │
│                                                             │
│  后端微服务 → 从请求头获取userId                           │
│               └→ 返回用户相关数据                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 已完成的修改

### 1. AI项目配置 (D:\ClaudeCodeProjects\CCAIAgent\damai-smart-ticket\.env)

```properties
# 所有 API 都通过网关调用
JAVA_API_BASE_URL=http://localhost:6085
JAVA_API_PROGRAM_URL=http://localhost:6085
JAVA_API_ORDER_URL=http://localhost:6085
```

### 2. java_api_client.py

添加了 Token 支持：
- `set_token(token)` - 设置用户 Token
- `set_code(code)` - 设置渠道编码
- 请求头自动携带 Token 和 code

### 3. agent.py

修改为从请求头获取 Token：
- 从 `Authorization` 请求头获取 Token
- 从 `code` 请求头获取渠道编码
- 设置到 Java API 客户端

## Token 传递流程

```
┌─────────────────────────────────────────────────────────────┐
│                    Token 传递流程                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  1. 用户在全栈项目登录                                      │
│     └→ Token 存入 Cookie (Admin-Token)                     │
│                                                             │
│  2. 用户打开 AI 客服                                        │
│     └→ 前端从 Cookie 获取 Token                            │
│     └→ 通过 postMessage 或 API 请求传递 Token              │
│                                                             │
│  3. AI 项目后端接收 Token                                   │
│     └→ 从请求头获取 Token                                  │
│     └→ 设置到 Java API 客户端                              │
│                                                             │
│  4. AI 项目调用全栈 API                                     │
│     └→ 请求头携带 Token                                    │
│     └→ 网关验证 Token                                      │
│     └→ 网关获取 userId                                     │
│     └→ 网关将 userId 添加到请求头                          │
│                                                             │
│  5. 后端微服务获取 userId                                   │
│     └→ 返回用户相关数据                                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```
