# 支付方式-相关问题与回答

## 支持哪些支付方式？
亲，大麦支持以下支付方式：
1. 支付宝
2. 微信支付
3. 银行卡（借记卡/信用卡）
4. 花呗分期（部分演出支持）
5. 大麦余额支付

具体支持的支付方式以订单结算页面显示为准。

## 支付失败怎么办？
亲，支付失败可能有以下原因：
1. 银行卡余额不足或限额，请确认卡内余额或联系银行调整限额
2. 网络超时，请检查网络后重试
3. 支付密码错误，请确认密码后重试
4. 支付渠道维护，请稍后重试或更换支付方式

如多次支付失败，建议更换其他支付方式尝试。

## 支付成功但订单显示未付款怎么办？
亲，如支付成功但订单状态未更新，可能是系统延迟，请等待 5-10 分钟后刷新页面查看。如仍未更新，请保留支付截图，联系客服处理。

## 可以用花呗分期付款吗？
亲，部分演出支持花呗分期，具体以订单结算页面显示为准。花呗分期可能会收取手续费，详情请参考支付宝页面说明。

## 支付时提示"风控拦截"怎么办？
亲，如支付时提示风控拦截，可能是支付行为触发了安全风控规则。建议：
1. 更换支付方式
2. 稍后重试
3. 联系客服核实账户状态

## 可以开发票吗？
亲，可以的。演出票务发票由大麦网开具，您可以在订单详情页申请电子发票。发票将在演出结束后 7 个工作日内开具，发送至您的邮箱。部分演出支持开具增值税专用发票，具体以页面显示为准。
