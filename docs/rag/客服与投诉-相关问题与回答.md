# 客服与投诉-相关问题与回答

## 人工客服电话是多少？
亲，大麦客服热线：1010-3721（按市话收费）。
服务时间：每天 9:00-21:00。
高峰期间可能需要排队等候，建议避开演出开票高峰期拨打。

## 在线客服怎么联系？
亲，在线客服联系方式：
1. 大麦APP → 我的 → 客服中心 → 在线客服
2. 大麦官网 → 右下角"在线客服"
3. 微信搜索"大麦"公众号 → 底部菜单"联系客服"

在线客服服务时间：每天 9:00-21:00。

## 怎么投诉？
亲，如果对服务不满意，可以通过以下渠道投诉：
1. 在线客服：直接向客服人员反馈
2. 客服热线：1010-3721 转投诉专线
3. 邮箱投诉：service@damai.cn
4. 大麦APP → 我的 → 客服中心 → 投诉建议

我们会在 3 个工作日内处理您的投诉并回复。

## 客服回复太慢怎么办？
亲，演出开票期间咨询量较大，客服回复可能会延迟。建议：
1. 优先使用在线客服（排队时间通常比电话短）
2. 避开开票高峰期（开票后 1 小时内）
3. 非紧急问题可发送邮件至 service@damai.cn

## 可以投诉演出方吗？
亲，如果演出方存在违规行为（如虚假宣传、演出质量严重不达标），可以通过以下方式投诉：
1. 向大麦客服反馈，我们会协助沟通
2. 向当地文化市场综合执法部门投诉
3. 向消费者协会投诉（12315）

## 订单有问题找谁处理？
亲，订单相关问题请按以下顺序处理：
1. 查看订单详情页的"帮助中心"
2. 联系在线客服（推荐，处理更快）
3. 拨打客服热线 1010-3721

请提前准备好订单号，以便客服快速定位问题。

## 可以要求开发票吗？
亲，可以。大麦支持开具电子发票：
1. 订单支付完成后，在订单详情页点击"申请发票"
2. 选择发票类型（个人/企业）
3. 填写发票信息
4. 电子发票将在 3 个工作日内发送至您的邮箱

温馨提示：部分演出可能不支持开票，具体以订单页面显示为准。

## 客服说不能处理怎么办？
亲，如果一线客服无法解决您的问题，可以：
1. 要求转接主管或高级客服
2. 拨打投诉专线
3. 发送详细问题描述至 service@damai.cn
4. 通过消费者协会（12315）维权

## 海外用户怎么联系客服？
亲，海外用户可以通过以下方式联系：
1. 邮箱：service@damai.cn
2. 大麦APP在线客服（需联网）
3. 微信公众号"大麦"在线客服

海外拨打客服热线请加拨 +86-10-10103721。
