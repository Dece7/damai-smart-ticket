# 优惠活动-相关问题与回答

## 有哪些优惠活动？
亲，大麦常见的优惠活动包括：
1. 早鸟票：开售初期享受折扣价，数量有限
2. 优惠券：满减券、折扣券等，可在结算时使用
3. 满减活动：满一定金额立减
4. 学生票：部分演出提供学生优惠价
5. 团体票：部分演出支持团购优惠

具体优惠以演出详情页和活动页面显示为准。

## 优惠券怎么领取和使用？
亲，优惠券领取方式：
1. 大麦APP首页"领券中心"
2. 演出详情页领取
3. 活动页面领取

使用方法：下单结算时，在支付页面选择可用优惠券即可自动抵扣。

## 优惠券有使用限制吗？
亲，优惠券通常有以下限制：
1. 有效期：请在有效期内使用
2. 使用门槛：如"满 500 减 50"，订单金额需达到门槛
3. 适用范围：部分优惠券仅限特定演出或品类使用
4. 使用次数：每张优惠券一般限使用一次

具体限制以优惠券详情页说明为准。

## 早鸟票是什么？
亲，早鸟票是演出开售初期提供的优惠票，价格通常比正式票价低 10%-30%。早鸟票数量有限，售完即止，建议尽早购买。

## 学生票怎么买？
亲，如演出支持学生票，您需要在购票时选择"学生票"票档，并在入场时出示有效学生证件进行核验。未携带学生证可能需要补差价。

## 买了票之后有更便宜的活动怎么办？
亲，已购买的订单不支持价格调整。如您发现后续有更优惠的活动，可以考虑退票后重新购买，但退票需符合该演出的退票政策。
