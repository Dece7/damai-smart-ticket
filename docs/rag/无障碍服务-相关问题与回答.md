# 无障碍服务-相关问题与回答

## 场馆有无障碍设施吗？
亲，大部分大型场馆设有无障碍设施，包括：
1. 无障碍通道：轮椅通道、无障碍电梯
2. 无障碍座位：专为轮椅使用者设计的观演区域
3. 无障碍卫生间：配备扶手和紧急呼叫装置

具体设施以场馆实际情况为准，建议提前联系场馆确认。

## 轮椅用户怎么购票？
亲，轮椅用户可通过以下方式购票：
1. 在大麦APP选择"无障碍座位"票档（如有）
2. 联系客服预约无障碍座位
3. 部分演出支持现场购买无障碍座位

建议提前购票，无障碍座位数量有限。

## 有陪同人员的优惠吗？
亲，部分场馆和演出为残障人士提供陪同人员免费或优惠入场政策。具体以演出详情页说明为准，如未注明，陪同人员需正常购票。

## 有助听设备吗？
亲，部分大型场馆提供助听设备租赁服务，包括：
1. 感应环系统：兼容助听器
2. 无线接收耳机：提供现场音效增强

建议提前联系场馆确认是否提供助听设备及租赁方式。

## 视障人士可以带导盲犬入场吗？
亲，根据相关法规，导盲犬可以随视障人士进入公共场所。但部分场馆可能有特殊规定，建议提前联系场馆确认。

## 场馆有无障碍停车位吗？
亲，大部分大型场馆设有无障碍停车位，位于场馆入口附近。数量有限，建议提前到达。停车证件和收费标准以场馆现场规定为准。
