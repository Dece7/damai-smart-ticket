# 选座指南-相关问题与回答

## 可以自己选座位吗？
亲，部分演出支持在线选座，您可以在购票页面查看是否有"选座"标识。如支持选座，点击"选座购买"即可进入座位图页面，选择您心仪的座位。如不支持选座，系统会自动为您分配座位。

## 选座有什么技巧吗？
亲，选座建议如下：
1. 演唱会：内场前排视野最佳，看台A区性价比最高
2. 话剧/相声：前排中间位置观赏体验最好，建议避开两侧偏位
3. 音乐节：一般为站立区，无固定座位
4. 具体场馆的最佳观赏位置，可参考演出详情页的"座位图"说明

## 选了座位后可以换吗？
亲，非常抱歉，订单一旦生成，座位信息无法更改。如需更换座位，需要先退票再重新购买，但退票需符合该演出的退票政策。

## 为什么有些座位显示灰色不可选？
亲，灰色座位表示该座位已被其他用户购买或预留，暂时无法选择。您可以选择其他可选座位。

## 两个人可以选相邻的座位吗？
亲，如您需要购买相邻座位，建议在同一次下单中选择多个座位，系统会优先为您分配相邻位置。分开下单可能无法保证座位相邻。

## 大麦的座位图准确吗？
亲，座位图仅供参考，实际座位位置可能因场馆调整略有差异。最终以现场实际座位为准。

## 选座时显示"该座位不可选"是什么意思？
亲，这表示该座位已被其他用户选中或已售出，暂时无法选择。建议您选择其他可用座位，或者稍后再试（有时其他用户的选座会超时释放）。

## 选座失败怎么办？
亲，选座失败可能原因：
1. 座位已被他人选中 → 换其他座位
2. 网络延迟 → 刷新页面重试
3. 选座超时 → 重新进入选座页面
4. 系统繁忙 → 稍后重试
如多次失败，建议联系客服协助。

## 选座需要额外付费吗？
亲，大部分演出选座不额外收费，票价已包含座位位置因素。部分特殊演出可能收取选座服务费，具体以演出详情页说明为准。

## 什么是"系统自动分配座位"？
亲，部分演出不支持自主选座，系统会根据您的票档自动分配座位。分配规则：
1. 同一订单的座位尽量安排在一起
2. 优先分配视野较好的位置
3. 具体座位以出票后显示为准

## 选座页面加载很慢怎么办？
亲，选座页面加载慢可能是由于：
1. 网络不稳定 → 切换网络重试
2. 同时选座人数过多 → 稍后重试
3. 浏览器缓存问题 → 清除缓存后重试
建议使用大麦APP选座，体验通常比网页更流畅。

## 可以选连座吗？
亲，可以。在同一订单中选择相邻座位即可。如果无法选到连座，说明相邻座位已被其他人选中或售出。
