# 安全与隐私-相关问题与回答

## 大麦的支付安全吗？
亲，大麦采用多重安全措施保障支付安全：
1. SSL 加密传输：所有支付数据加密传输
2. 支付渠道正规：对接支付宝、微信支付等正规支付平台
3. 风控系统：实时监控异常交易
4. 资金托管：订单资金由第三方支付平台托管

请勿向任何人透露支付密码和验证码。

## 个人信息会被泄露吗？
亲，大麦严格遵守《个人信息保护法》，采取以下措施保护用户隐私：
1. 数据加密存储
2. 访问权限控制
3. 定期安全审计
4. 不会向第三方出售用户信息

如发现个人信息被泄露，请立即联系客服。

## 账号被盗怎么办？
亲，如果发现账号被盗，请立即：
1. 通过"忘记密码"功能重置密码
2. 联系客服冻结账号
3. 检查是否有异常订单，如有请联系客服处理
4. 如涉及资金损失，建议报警处理

## 收到"大麦"的短信/电话是真的吗？
亲，请注意辨别真假：
1. 大麦官方短信通常以 1069 开头
2. 官方客服电话：1010-3721
3. 不会要求您提供密码或验证码
4. 不会要求您转账或汇款

如收到可疑信息，请勿点击链接，直接联系官方客服核实。

## 实名制信息安全吗？
亲，实名制信息由大麦系统加密存储，仅用于：
1. 购票身份验证
2. 入场身份核验
3. 防止黄牛倒票

不会将实名信息用于其他用途，也不会泄露给第三方。

## 退款会退到哪里？
亲，退款会原路退回至您的付款账户：
1. 支付宝付款 → 退回支付宝
2. 微信付款 → 退回微信
3. 银行卡付款 → 退回银行卡（1-3 个工作日到账）

退款到账时间因支付渠道不同而异，一般 1-7 个工作日。

## 可以删除我的浏览记录吗？
亲，可以。操作路径：
1. 大麦APP → 我的 → 设置 → 隐私设置
2. 选择"清除浏览记录"

清除后不会影响您的订单和收藏记录。

## 大麦会给我推送广告吗？
亲，大麦会根据您的浏览和购票偏好推送相关演出信息。如果您不想接收：
1. 大麦APP → 我的 → 设置 → 消息通知
2. 关闭"个性化推荐"

关闭后仍会收到订单状态变更等重要通知。

## 儿童的隐私怎么保护？
亲，对于 14 岁以下儿童用户：
1. 购票需由监护人操作
2. 不会主动收集儿童个人信息
3. 儿童入场需由监护人陪同

如需删除儿童相关信息，请联系客服处理。
