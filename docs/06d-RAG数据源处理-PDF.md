# RAG 复杂数据源处理 - PDF

> 当前项目只处理 Markdown 文件，实际开发中数据源复杂多样：PDF、Word、Excel、图片。不同格式需要不同的预处理管线。

---

## 一、数据源复杂度对比

| 格式 | 复杂度 | 核心难点 |
|------|--------|---------|
| Markdown | ⭐ | 文本结构清晰，直接加载 |
| Word (.docx) | ⭐⭐ | 格式丢失、嵌入图片 |
| Excel | ⭐⭐ | 表格结构化、多 Sheet |
| 网页 HTML | ⭐⭐ | 去标签、去广告、提取正文 |
| 图片 | ⭐⭐⭐⭐ | 需要 OCR 或多模态理解 |
| **💥PDF💥** | ⭐⭐⭐⭐⭐ | 表格、图片、页眉页脚、水印、扫描件 |

**PDF 是 RAG 系统中最复杂的数据源。**

---

## 二、PDF 处理的五大难点

### 1. 💥纯文本提取

纯文本 PDF（有文本层）可以直接提取：

```python
import pdfplumber
with pdfplumber.open("doc.pdf") as pdf:
    for page in pdf.pages:
        text = page.extract_text()
```

扫描件 PDF（无文本层）需要 **💥OCR**：

```python
# 图像预处理 → OCR 识别
import pytesseract
from PIL import Image
text = pytesseract.image_to_string(Image.open("page.png"), lang="chi_sim")
```

### 2. 💥页眉页脚处理

**问题**：每页顶部/底部重复出现"大麦网用户协议 v2.0"、页码等信息，切分后每个 chunk 都带着，纯噪音。

```
页眉: "大麦网购票服务协议"
正文: "第一条 退票规则..."
页脚: "第 3 页 / 共 10 页"

切分后 chunk: "大麦网购票服务协议\n第一条 退票规则...\n第 3 页"
→ embedding 编码了页眉页脚，干扰语义
```

**解决**：检测重复出现的行，自动过滤掉。

### 3. 💥水印去杂音

**问题**：PDF 里的半透明文字水印（"内部资料"、"仅供参考"）会被 OCR 当成正文提取。

```
原文: "退票政策如下"
水印: "仅供内部使用"
OCR 提取: "退票政策如下仅供内部使用"  ← 水印文字混入
```

**解决**：水印通常有固定位置和样式（半透明、斜体），在图像预处理阶段滤除。

### 4. 💥表格识别

**问题**：PDF 表格只提取文字会丢失行列结构。

```
原始表格：
┌────────┬────────┬────────┐
│ 票档    │ 价格    │ 余票   │
├────────┼────────┼────────┤
│ 看台票  │ 480元   │ 500张  │
│ 内场票  │ 1280元  │ 200张  │
└────────┴────────┴────────┘

只提取文字: "票档 价格 余票 看台票 480元 500张 内场票 1280元 200张"
→ 丢失行列对应关系
```

**解决**：转成 Markdown 表格或结构化 JSON：

```markdown
| 票档 | 价格 | 余票 |
|------|------|------|
| 看台票 | 480元 | 500张 |
| 内场票 | 1280元 | 200张 |
```

### 5. 💥图片处理

**问题**：PDF 中的图片（海报、示意图、流程图）包含重要信息，只提取文本会丢失。

**解决**：用多模态模型生成图片描述，描述文本存入向量库：

```
图片 → 多模态模型（GPT-4V / DashScope）→ "这是一张演唱会海报，演出时间为2026年8月15日..."
→ 描述文本存入向量库
```

## 三、多模态 RAG

**传统 RAG**：只检索文本，图片内容检索不到。

**多模态 RAG**：文本和图片在同一个向量空间里检索。

```
用户问: "海报上写的演出时间是什么"
  ↓
传统 RAG: 检索文本 → 找不到（海报是图片）
多模态 RAG: 检索文本 + 图片描述 → 找到海报描述 → 回答
```

**多模态 Embedding**（如 DashScope tongyi-embedding-vision-plus）：

```
文本 → embedding → 向量（同一个向量空间）
图片 → embedding → 向量（同一个向量空间）
→ 文本和图片可以混合检索
```

---

## 四、企业级 PDF 处理管线

```
PDF 文件
  ↓
页眉页脚检测 → 过滤重复行
  ↓
水印检测 → 图像预处理去除
  ↓
文本提取（pdfplumber / Tesseract OCR）
  ↓
表格识别 → 转 Markdown 或 JSON
  ↓
图片提取 → 多模态模型生成描述
  ↓
清洗后的文本 + 结构化表格 + 图片描述
  ↓
切分 → 向量化
```

## 五、本项目现状

当前项目只处理 Markdown 文件，用 `TextLoader` 加载：

```python
loader = DirectoryLoader("docs/rag/", glob="**/*.md", loader_cls=TextLoader)
```

**为什么只做 Markdown**：
- 知识库内容是自己写的 Markdown，格式规范
- 不需要处理 PDF、图片等复杂格式
- Demo 项目，投入产出比不高
